# Lesson 1: Computer Basics

## Why This Matters

Developers give computers precise instructions. Before installing Flutter, you
need a shared vocabulary for the computer, its information, and its programs.

## What You Will Learn

- Identify an operating system, application, and process.
- Explain the difference between a file and a folder.
- Read a simple path.
- Locate a project without changing or deleting it.

![Map connecting the operating system, applications, processes, files, folders, paths, and terminal](../images/computer_basics_map.svg)

## New Words

| Word | Meaning | Example |
| --- | --- | --- |
| **Operating system** | The main software that manages the computer | Windows or macOS |
| **Application** | A program used to do work | Chrome, VS Code, Coach Score |
| **Process** | A running instance of an application | A currently running Chrome window |
| **File** | A named piece of stored information | `main.dart` or `README.md` |
| **Folder** | A container that organizes files and other folders | `Documents` or `volleyball_stats` |
| **Path** | The address of a file or folder | `volleyball_stats/lib/main.dart` |

An application stored on disk is not the same as a process. Opening VS Code
starts a process. Closing its last window normally stops that process.

## Teacher Demonstration

1. Open Finder on macOS or File Explorer on Windows.
2. Open the `Documents` folder.
3. Create a folder named `student-projects` if classroom policy permits.
4. Point to the folder name and its path.
5. Open a text file and identify its filename and extension.

## Try It Yourself

On paper, label each item as **OS**, **application**, **process**, **file**,
**folder**, or **path**:

1. Windows 11
2. Visual Studio Code
3. A currently running copy of Visual Studio Code
4. `main.dart`
5. `Documents/student-projects`
6. `student-projects`

Then use Finder or File Explorer to locate your `Documents` folder. Do not move
or delete files you do not recognize.

## Checkpoint

Explain this path to a partner:

```text
student-projects/hello_flutter/lib/main.dart
```

A good explanation identifies three folders and the `main.dart` file. You
should also be able to explain why an application and a process are different.

## Think Like an HCI Designer

Finder and File Explorer are interfaces. Folder icons, filenames, colors, and
selection highlights are representations that help people understand stored
information. Ask: how does the interface show which folder is currently open?
