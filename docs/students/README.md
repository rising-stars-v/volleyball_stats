# Coach Score Student Course

Welcome! This course teaches software development by starting with people and
problems—not with a large block of code.

You will learn how computers organize information, run a Flutter app, observe
how people use an interface, design an improvement, and use AI carefully to
help implement one small change.

## How to Use This Course

Complete the required lessons in order. Each lesson has one checkpoint. Stop
and ask a teacher for help if the checkpoint does not pass.

You do not need Android, iOS, GitHub Copilot, or a social-media account on the
first day. Chrome is the simplest place to run Coach Score.

## Required Learning Path

| Lesson | What you will accomplish | Suggested time |
| --- | --- | ---: |

| [3. Install Flutter](03-flutter-setup/README.md) | Prepare a Windows or macOS computer | 45–90 min |
| [4. Build Your First Flutter App](04-build-your-first-flutter-app.md) | Create Hello World and try hot reload | 45 min |
| [5. Run Coach Score](05-run-coach-score.md) | Download, run, and explore this project | 30 min |
| [6. HCI With Everyday Apps](06-hci-with-everyday-apps.md) | Learn interface, representation, goal, task, action, and feedback | 45–60 min |
| [7. Observe Coach Score](07-observe-coach-score.md) | Collect evidence from a user instead of guessing | 45 min |
| [8. Design and Test an Improvement](08-design-and-test-an-improvement.md) | Sketch an idea and test it before coding | 45–60 min |
| [9. Copilot Setup and Safety](09-copilot-setup-and-safety.md) | Configure an optional AI assistant safely | 30–45 min |
| [10. First AI-Assisted Change](10-first-ai-assisted-change.md) | Make, review, and test one small contribution | 60–90 min |

## Classroom Safety

- Use only accounts approved by your school and parent or guardian.
- Never share passwords, security codes, tokens, private messages, or student records.
- Use fictional names and data while practicing.
- Read commands before running them.
- Review every AI-generated change before accepting it.
- Ask for help when a command could delete, publish, purchase, or share something.

Start with [Lesson 1: Computer Basics](01-computer-basics.md).
