# Student Glossary

| Term | Beginner-friendly meaning |
| --- | --- |
| Action | One thing a user does, such as selecting or typing |
| Application | A whole software product used to complete work |
| Argument | Information given to a command |
| Command | A text instruction given through a shell |
| Directory | Another word for folder |
| Feedback | What a system shows after an action |
| File | A named piece of stored information |
| Flutter SDK | Tools for creating, running, checking, and building Flutter apps |
| Folder | A container used to organize files and folders |
| Goal | The result a user wants |
| HCI | Human-Computer Interaction: studying and designing how people use technology |
| IDE | An application that combines code editing and development tools |
| Interface | The parts through which a user and system communicate |
| Path | The address of a file or folder |
| Process | A running application; in HCI, it can also mean ordered task steps |
| Representation | A symbol, word, color, sound, or layout that stands for meaning |
| Repository | A project whose files and history are tracked together |
| Shell | A program that reads terminal commands |
| State | What is true in the application at a particular moment |
| Task | A piece of work a user chooses to complete |
| Terminal | A text interface for entering commands and viewing results |
| Usability | How effectively, efficiently, and comfortably people complete tasks |
| Widget | A Flutter building block for part of an interface |
