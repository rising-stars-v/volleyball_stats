# Advanced HCI Concepts

Use this reference after learning the core ideas in
[Lesson 6](../06-hci-with-everyday-apps.md).

## Affordance

An **affordance** is what an object allows a person to do. A button allows
pressing. A text field allows entering text.

## Signifier

A **signifier** is a clue that communicates what to do. A button's border,
label, color, and placement can signal that it is selectable.

## Mapping

**Mapping** is the relationship between a control and its result. If an arrow
points right and moves to the next photo, the mapping feels natural. If it
moves backward, users may be surprised.

## Constraint

A **constraint** limits possible actions to prevent confusion or mistakes. A
Send button might remain unavailable until a recipient is entered. A character
counter may limit the length of a message.

## Mental Model

A **mental model** is the explanation a user carries in their mind about how
something works. A user may imagine that deleting a message destroys it
immediately, although the application might first move it to Trash. If the
interface and the user's mental model disagree, errors can follow.

## Representation Detective

For each item, write what it represents and whether its meaning is clear:

- Paperclip
- Trash can
- Heart
- Speech bubble
- Bookmark
- Red notification badge
- Three dots

Invent a new symbol for “save for later.” Test it with a partner without
explaining it. If your partner cannot guess its meaning, add a label or redesign
the symbol.
