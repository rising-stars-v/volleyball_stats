# Computer Basics Extra Practice

Use these activities after Lesson 1, for homework, or when a student finishes
the required exercise early.

## Compare Windows and macOS Paths

These paths point to a similar file:

Windows:

```text
C:\Users\Maya\Documents\School\Science\volcano-notes.txt
```

macOS:

```text
/Users/Maya/Documents/School/Science/volcano-notes.txt
```

Windows normally uses a backslash (`\`) between path parts. macOS normally uses
a forward slash (`/`). In both examples, `volcano-notes.txt` is the file at the
end.

Answer:

1. Which folder contains `volcano-notes.txt` directly?
2. Which school subject contains the file?
3. Which folder appears immediately before `Science`?
4. Why would `School/volcano-notes.txt` point to a different location?

## Create a Safe Practice Folder

This activity is optional. Work only inside your own `Documents` folder, and
ask your teacher before creating folders on a managed school computer:

1. Open Finder on macOS or File Explorer on Windows.
2. Create a folder named `computer-basics-practice`.
3. Open Notepad on Windows or TextEdit on macOS.
4. On macOS, choose **Format → Make Plain Text** if needed.
5. Type: `I can identify a file, folder, and path.`
6. Save the file as `learning-notes.txt` inside the practice folder.
7. Locate the file and identify its path.

Your result should resemble:

```text
Documents/
  computer-basics-practice/
    learning-notes.txt
```

## Safety Challenge

Which actions are safe?

- A. Open your own practice folder.
- B. Delete an unfamiliar system folder to create space.
- C. Rename `learning-notes.txt` inside your practice folder.
- D. Move another student's folder without asking.
- E. Ask a teacher before changing something you do not recognize.

For the path questions:

1. `Science`
2. Science
3. `School`
4. It leaves out the `Science` folder.

For the safety challenge, **A, C, and E** are safe. Do not delete unfamiliar
folders or change another student's work.
