# Useful Student Commands

Run project commands from the folder containing `pubspec.yaml`.

| Command | Purpose |
| --- | --- |
| `pwd` | Show the current folder on macOS |
| `Get-Location` | Show the current folder in Windows PowerShell |
| `ls` | List files on macOS |
| `Get-ChildItem` | List files in Windows PowerShell |
| `cd folder-name` | Enter a folder |
| `cd ..` | Return to the parent folder |
| `git status` | Show tracked file changes |
| `flutter doctor -v` | Diagnose the Flutter environment |
| `flutter devices` | List targets Flutter can run on |
| `flutter pub get` | Download project packages |
| `flutter run -d chrome` | Run the app in Chrome |
| `dart format .` | Format Dart files |
| `flutter analyze` | Find static code problems |
| `flutter test` | Run automated tests |

While `flutter run` is active:

| Key | Purpose |
| --- | --- |
| `r` | Hot reload |
| `R` | Hot restart |
| `q` | Stop the app |

Commands that delete, publish, deploy, install system software, or request
credentials require extra care and teacher approval.
